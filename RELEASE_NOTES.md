# HardwarePro Lite v1.0.0 – Release Notes

**Edition:** Single-PC Offline Edition  
**Platform:** Windows 10 / 11 x64  
**Developer:** Kavindu Rasanja  
**Release line:** 1.0.0

## Product scope

HardwarePro Lite v1.0.0 brings the main hardware-shop workflow into one Windows desktop application:

`Quotation → Sales Order → Delivery Note → Invoice → Payment / Credit → Customer Ledger`

## Included in v1.0.0

- POS / sales
- Hardware-oriented unit handling and selling-unit conversions
- Product, category, brand and stock management
- Multiple price levels
- Customer credit limits and ledger
- Quotations
- Sales Orders and stock reservations
- Delivery Notes
- Supplier accounts
- Purchases / GRN
- Supplier credit and payments
- Cheque management
- Expenses
- Sales / purchase returns
- Business reports
- PDF and Excel export
- A4, A5 and 80mm invoice / receipt output
- Staff roles
- Audit log
- Local backup / restore
- Configurable receipt footer

## Data model

The Lite edition stores production data locally in SQLite. It is intended for a single active PC and does not require a permanent cloud service for normal operation.

## Deployment notes

Before using the system in a live business:

1. Configure the business details.
2. Create the Owner account and protect Owner / Manager credentials.
3. Confirm product base units and selling-unit conversion factors.
4. Test A4 / A5 / 80mm output using the exact printer.
5. Enter or import opening stock carefully.
6. Create and verify a backup.
7. Create individual staff accounts where required.
